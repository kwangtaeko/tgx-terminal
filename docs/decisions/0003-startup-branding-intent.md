# 0003. TGX 시작 브랜딩 요구

작성일: 2026-10-24
상태: UI 후속 구현 대기

## 요구

TGX Terminal 플러그인이 시작되어 Claude Code 또는 Codex CLI를 실행하는 동안, 공급자 자체 아이콘과 혼동되지 않는 **TGX 고유의 글자 또는 아이콘**을 짧게 표시한다. 사용자가 Claude Code 시작 시의 로딩 아이콘처럼 “TGX가 세션을 준비 중”임을 알 수 있어야 한다.

## 경계와 완료 조건

- 표시 주체는 공급자 CLI가 아니라 TGX 래퍼임을 명확히 한다. Claude 또는 Codex 브랜드를 대체하거나 모방하지 않는다.
- PTY 생성 전후의 시작 상태에만 나타나고, 첫 유효 화면 렌더, 시작 실패, 또는 세션 종료 때 제거한다.
- 입력, 승인 메뉴, Ctrl+C, 붙여넣기, 자식 CLI 출력의 순서나 내용을 바꾸지 않는다.
- 로고 자산 형식, 애니메이션, 정확한 위치와 접근성 표현은 UI 작업 단계에서 디자인과 함께 확정한다.

## 현재 결정

이번 제어 디코더 증분에는 UI를 추가하지 않는다. 후속 렌더러·탭 UI 계획이 이 요구를 명시적으로 소비하고, fixture 및 실제 Windows 터미널 검증에 시작·실패·종료 제거 시나리오를 포함한다.
