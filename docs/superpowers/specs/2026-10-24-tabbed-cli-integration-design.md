# 탭 CLI 통합 설계

`--tgx-tabs`에서만 `runCli`는 다중 PTY 수명주기를 사용한다. 기본 경로는 기존 단일 세션을 보존한다. `Ctrl+T n`, `]`, `[`, `x`는 각각 같은 provider 인자의 새 탭, 다음/이전 실행 탭 선택, 선택 탭 닫기다.

`MultiSessionManager`는 상태가 바뀔 때 예외를 흡수하는 변경 알림을 보낸다. CLI는 알림마다 선택 탭의 안전한 snapshot만 기존 renderer로 출력한다. 입력과 명령은 하나의 Promise 큐에서 순서대로 처리하며, 마지막 실행 탭이 종료되면 마지막 exit code를 반환하고 모든 보존 탭을 정리한 뒤 부모 터미널을 복구한다.

탭 바, 독립 스크롤 조작 UI, 시작 브랜딩은 포함하지 않는다.
