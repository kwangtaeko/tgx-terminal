# TGX 그림자 워드마크 설계

## 의도

TGX 시작 화면을 블록 ASCII 로고가 아닌, 투명한 터미널 배경 위에서 글자가 떠 보이는 TGX 전용 워드마크로 바꾼다. 사용자가 승인한 시안처럼 밝은 전면 글자와 오른쪽 아래로 밀린 어두운 그림자를 사용한다.

## 목표

- 시작 화면에만 적용하고 provider PTY 출력·입력 경계를 바꾸지 않는다.
- 기본 ANSI/xterm-256color에서 읽을 수 있는 밝은 전면과 어두운 남색 그림자를 사용한다.
- 높이가 충분한 경우 큰 `TGX` 글자와 그림자를 별도 행으로 그린다.
- 좁거나 낮은 terminal에서는 같은 색상 규칙의 한 줄 `TGX` 배지로 축소한다.
- 배경색, 사각 패널, 가짜 사용량, Codex·Claude 로고는 추가하지 않는다.

## 비교한 방식

1. 생성 이미지 파일을 startup 화면에 표시: 일반 Windows 터미널은 인라인 이미지 프로토콜을 보장하지 않아 제외한다.
2. 기존 block ASCII 글자: 사용자가 원한 그림자 글자 효과와 다르므로 제외한다.
3. ANSI 색상 텍스트를 두 위치에 그리기: 전면과 한 칸 오른쪽 아래 그림자를 안정적으로 표현하며 투명 배경과 PTY 호환성을 유지하므로 선택한다.

## 제약

- ASCII 텍스트와 ANSI SGR/CUP/EL만 사용한다.
- 마지막에는 SGR을 reset한다.
- 기존 행 수 경계(1행과 7행)를 넘지 않는다.
- 자동 테스트는 문자열·색상·좌표·경계만 검증하며, 실제 Windows 색상 인상은 수동 smoke 대상으로 남긴다.
